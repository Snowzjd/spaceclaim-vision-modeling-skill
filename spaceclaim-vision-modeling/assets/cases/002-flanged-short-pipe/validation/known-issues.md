# Known issues and retained assumptions

- `R1.5 mm` is an explicit midpoint choice inside the user-provided `R1..R2 mm` range, not a uniquely specified source dimension.
- The supplied perspective image is identified by hash but is not packaged until redistribution status is confirmed.
- The controlled evidence covers SpaceClaim 2022 R1 / API V21. Other API versions require a separate compatibility run.
- The image appears smoother around some hole entrances than the text specifies. No extra hole-edge treatment is added.
