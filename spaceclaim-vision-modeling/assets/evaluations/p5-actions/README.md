# P5 validation and navigation evidence

This is synthetic development evidence, not user-case acceptance or a release.
All new P5 operation contracts remain candidates.

## Independent guidance assessment

`raw-inputs.json`, `results.json`, and `evaluation.md` preserve the independent
44-action application. `initial-guides/` preserves the exact guidance bytes.
The assessment produced plans or refusals, not desktop or geometry results.

## Controlled V21 measurements

`runtime-snapshots.json` binds exact archived actions and reports to each run.
The initial failed probe is retained. Delta tests reuse the same synthetic
fixture without recreating, saving, or deleting geometry. A successful API call
alone is insufficient: the paired independent assertion must also pass.

Scope is root-level objects in the active document, millimetres and world
coordinates. The checks cover enumeration/count, bounds, volume, surface area,
planar face area/bounds-centre/normal, analytic type, axis-aligned cylinder and
cone dimensions, declared torus minor radius, supplied pattern positions,
names and named-group membership. They do not establish occurrence support,
area-centroid computation, arbitrary trimmed curved-face normals, automatic
pattern recognition or automatic recognition of every fillet.

Portable harnesses omit only the documented machine configuration assignments.
Supply these and package a new `.scscript` to reproduce a test. The portable
derivatives were not the exact configured archives executed; both original
configured hashes remain recorded. Raw action snapshots and reports retain
their exact bytes. None of the test fixtures is a modeling recipe or default
dimension set in the atomic library.

## Native persistence and visual observations

The public native fixture is linked from the preceding P4 evidence.
`reopen-evidence.json` records closing one already-saved unchanged document,
reopening it, and a separate read-only identity/count/bounds/volume check.
`reopen-observation.json` is explicitly a machine-path-redacted report
derivative, with its original report hash retained. `host-checks.json` compares
file identity and declared save/reopen observations; those host functions do
not perform the actual CAD actions.

`visual-evidence.json` binds seven raw screenshots to the native file, view,
selection, expected observation and occlusion. These observations verify only
the listed navigation variants. Spin-tool left-drag is not middle-button drag.
The clipped spin diagnostic is not a final acceptance view. Screenshots do not
establish exact dimensions, hidden geometry, universal controller mappings, or
visual agreement for a future model. No requested-export/reimport runtime
evidence was collected in P5.
