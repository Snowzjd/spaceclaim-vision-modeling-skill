`save-report.json` is the unchanged report from the controlled V21 save action.
`save-evidence.json` binds the exact action archive, synthetic native output and
configured test provenance. `save-test.py` removes only the two machine-specific
configuration assignments; the portable harness is not an independently run
archive. Supply a new run directory and the action path before packaging it.

The independent `raw-inputs.json`, `results.json` and `evaluation.md` exercise
EX/ER guidance on synthetic states, errors and signatures. A proposed click,
patch, save decision or observation in these records is not a desktop event,
an executed patch, or a successfully repaired model. Host-tool tests separately
exercise temporary-file and event behavior. Per-operation records identify the
exact artifacts and the limited layer each check supports.

targeted corrections. `initial-guides/` preserves their original guide bytes;
the other current guides remain unchanged except EX-04's non-behavioral removal
of a body-count description. Historical `runs/p4-independent/` locators in the
unchanged records refer to the same-named, hash-identical files in this bundle.

bundle. Do not transfer that result to another EX/ER guide. Native reopen and
