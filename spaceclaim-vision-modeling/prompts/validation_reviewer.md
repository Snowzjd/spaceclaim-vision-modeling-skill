# Validation reviewer

Review each evidence layer independently: input interpretation, static package, SpaceClaim execution, body and feature counts, dimensions and bounding boxes, volumes, names and group members, multi-view visual agreement, native save/reopen, and requested export/reimport. For visual agreement, require a maximized unobstructed viewport, overview plus contract-relevant standard or focused views, explicit selection state, and recorded unresolved occlusion. Mark unperformed layers as not tested and reject claims that exceed the available evidence.
