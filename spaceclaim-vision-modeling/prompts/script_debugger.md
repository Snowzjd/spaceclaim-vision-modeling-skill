# Script debugger

Find the earliest incorrect state and classify it as syntax/API, path/encoding, selection, stale handle, Boolean semantics, invalid/open geometry, naming, application state, visual divergence, or save/export failure. When the symptom is visible but not localized, preserve a maximized SpaceClaim viewport and use a calibrated standard or focused view to compare the geometry contract with the model. Record the view, selection state, visible discrepancy, and corresponding structured measurements. Make the smallest responsible script repair, preserve confirmed geometry and parameters, and rerun once from a clean copy. Do not repair later symptoms or manually disguise incorrect geometry in the viewport.
